# 🔐 Robust Federated Deep Learning-Based Intrusion Detection for Heterogeneous IoT Networks

## 📌 Overview
This project implements a **Federated Learning-based Intrusion Detection System (FL-IDS)** designed for heterogeneous IoT environments.  
The system trains distributed deep learning models across multiple simulated clients without sharing raw data, improving privacy and robustness.

---

## 🚀 Key Features
- Federated Learning using Flower
- Non-IID client data distribution
- Deep Neural Network IDS model (PyTorch)
- Label-flipping attack simulation
- Robust aggregation (Median Defense)
- Centralized vs Federated comparison
- Confusion matrix & performance metrics

---

## 🧠 Technologies
- Python
- PyTorch
- Flower Federated Framework
- Scikit-learn
- NumPy / Pandas

---

## 📊 Dataset
NSL-KDD dataset used for intrusion detection evaluation.

## 🏗 Architecture
1️⃣ Data preprocessing

5️⃣ Evaluation & visualization

- Federated Accuracy ≈ **85%**
- Centralized Accuracy ≈ **91%**
